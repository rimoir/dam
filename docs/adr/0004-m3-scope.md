# 0004. M3 범위

## 상태

채택. 2026-11-26.

## 결정

M3는 GitHub 이슈 어댑터까지 포함한다. 이슈 번호로 작업을 시작하면 어댑터가 제목, 이슈 링크, 완료 기준 목록을 읽어 작업 노트에 넣는다. GitHub 전용 명령은 어댑터 한 곳에만 둔다.

CI와 머지 규칙은 이 범위보다 먼저 #26에서 둔다. 그 결정은 `docs/adr/0003-ci-and-merge.md`다. 스펙을 쓸 때 기준 커밋은 `c2f3725`였고, 그때는 0003이 비어 있어 M3 범위를 0003으로 적었다. #27이 0003을 CI 결정으로 먼저 썼다. 그래서 이 범위 기록은 0004다.

PR 본문에 이슈 링크를 넣는 일과 현황판을 GitHub 상태로 갱신하는 일은 이 기록의 뒤 이슈다. 이 변경은 이슈를 읽어 작업을 시작하는 데까지다.

## 이유

HR P가 2026-11-26에 M3를 어댑터까지 포함하고 CI도 같이 하되, CI를 먼저 하기로 했다. 규칙과 노트가 GitHub를 직접 부르지 않게 하려고다.

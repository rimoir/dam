# 0001. writing-plans 계획 경로

## 상태

채택. 2026-11-25.

## 결정

writing-plans의 계획 파일은 `.team/sessions/<이슈번호>/task.md`에 둔다. superpowers 파일은 고치지 않는다. 경로는 `.rulesync/rules/dam.md`에 적고, `CLAUDE.md`와 `AGENTS.md`는 그 생성물이다.

## 이유

superpowers v7.0.2 `skills/writing-plans/SKILL.md` 16행은 계획을 `docs/superpowers/plans/YYYY-MM-DD-<feature-name>.md`에 저장하라고 한다. dam의 작업 노트는 `.team/sessions/<이슈번호>/`다.

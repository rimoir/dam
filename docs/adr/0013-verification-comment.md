# 0013. 검증 코멘트가 검토 기록인지

## 상태

채택. 2026-11-28. 훅 파일과 격리 코드는 이 결정이 바꾸지 않는다. 새 토큰은 없다.

## 결정

검토 기록인 검증 코멘트는 네 줄이다.

```
세션 id: <식별자>
헤드 SHA: <40자리 소문자 16진수>
확인 방법: <실행한 명령>
증거 요약: <한 줄>
```

세션 id는 영숫자로 시작하고 영숫자, `.`, `_`, `-`만 있으며 80자를 넘지 않는다. 확인 방법과 증거 요약은 비어 있으면 안 된다.

명령은 `python3 scripts/team-session.py verify-comment --head <지금 SHA> --text <코멘트>`다. 표준 출력은 `검토 기록`, `아님`, `무효` 중 하나다. 종료 0은 `검토 기록`일 때다.

세션 id가 없거나 형식이 틀리거나, 헤드 SHA나 확인 방법이나 증거가 없으면 `아님`이다. 그건 검토 기록이 아니다. 헤드 SHA가 지금 PR 헤드와 다르면 `무효`다. 그 검증은 다시 해야 한다. 첫 줄 표식만 있는 글은 `아님`이다.

이 판정은 코멘트 문자열과 기대 헤드만 본다. 깃과 노트를 열지 않고 gh를 부르지 않는다.

PR에 올리는 쓰기는 `scripts/issue_tracker.py`의 `comment_on_pull`뿐이다. 본문이 `검토 기록`이 아니면 쓰지 않는다. `commanded`가 아니면 기존과 같이 거부한다. 이슈 라벨과 이슈 닫기는 그대로 하지 않는다.

만든 세션 id와 검증 세션 id를 비교하는 머지 검사는 이 결정 밖이다.

## 이유

세션 id나 헤드 SHA가 없는 코멘트가 검토 기록으로 통과하면, 만든 세션이 같은 계정으로 자기 검증을 남길 수 있다. 헤드가 바뀐 뒤의 코멘트는 그 헤드의 검증이 아니다.

# 0005. 어댑터 선택

## 상태

채택. 2026-11-26. 일부 대체: 0007.

## 결정

issue-tracker 선택 결과는 `.team/adapters.lock`에 둔다. 형식은 한 줄 `issue-tracker: <이름>`이다. `#`로 시작하는 주석은 빼고, 다른 키는 읽지 않는다. 파일이 없거나 `issue-tracker` 키가 없으면 github다.

기본 구현은 github다. 이슈 읽기는 사람이 이미 로그인한 gh CLI의 `gh issue view`만 쓴다. 새 토큰을 만들지 않고, 이 파일과 노트와 로그에 토큰을 적지 않는다. lock 값이 github가 아니면 작업 시작은 이유를 알리고 노트를 만들지 않는다.

시험용 가짜 어댑터는 제품 이름이 아니다. 시험이 생성기에 읽기 객체를 넣어, gh로 읽었을 때와 같은 task.md 형식인지 본다.

쓰는 동작(코멘트, 라벨, 이슈 닫기, PR 열기)의 진입점은 `scripts/issue_tracker.py`에만 둔다. 사람이 그 동작을 직접 명령했을 때, 또는 ADR 0007 조건 안의 워커가 그 함수를 통해 gh를 부른다. 작업 시작 명령은 그 함수를 부르지 않는다. detect와 훅은 만들지 않는다. GitHub 밖으로는 보내지 않는다.

스펙은 이 선택을 0004로 적었다. #27이 0003을 먼저 썼고 M3 범위가 0004가 되었으므로 이 선택은 0005다.

## 이유

설계 Page의 adapters.lock 방향이다. 선택된 결과는 짧은 키와 값으로 두고, GitHub 명령은 어댑터 안에만 둔다. 기본값은 github이고 토큰은 없다.

# 상태 79

## 지금 상태

검증 시작은 역할 인자 `검증`으로 네 칸만 낸다. 스펙과 ADR 0010에 적었다. 그 검사는 아직 실패한다. `start-context`가 `--role`을 받지 않는다.

## 결정

- 입력 제한은 `start-context --role 검증` 인자다. 환경 변수와 훅 파일 변경은 쓰지 않는다.
- 출력은 완료 기준, BASE, HEAD, 검사 명령뿐이다. state.md를 열지 않는다.
- 만든 세션과 다른 세션은 출력 내용 차이로 본다. 세션 식별자는 만들지 않는다.
- 작성자 결정 메모: 이 문장은 검증 세션 시작 출력에 넣지 않는다.
- 보안 항목 경로는 ADR 0010의 제안만이다. 감지 코드는 없다.
- 로그 종류 칸은 기존 형식의 go다. 승인 문장은 내용에 적는다.

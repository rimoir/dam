# 상태 61

## 지금 상태

규칙 원본에 모드 넷과 첫 답 세 줄, 세션당 질문 한 번을 적었다. ADR 0008에 기준과 예시 네 개를 두었다. 규칙 원본은 39줄이다.

## 결정

- 모드 이름 줄은 `모드 이름: 조사, 작은 수정, 기능, 이어받기` 하나다.
- 예시와 고르는 기준은 규칙이 아니라 ADR 0008에 둔다. 고르는 기준은 추정이다.
- 상태 파일 첫 줄 형식은 `모드: <이름>`이다. 읽기와 쓰기는 뒤 이슈가 한다.
- 이 세션 로그의 도구 칸은 Cursor다.

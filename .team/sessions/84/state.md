# 상태 84

## 지금 상태

승인 없는 push, 다른 브랜치, main, force, PR 실패 시 로그 불변을 실패 검사로 먼저 둔다.

## 결정

- 워커 push는 승인 기록 줄이 있고 현재 브랜치와 대상이 그 작업 브랜치일 때만 한다.
- main, 다른 브랜치, force는 거부하고 이유를 낸다. git은 부르지 않는다.
- PR은 기존 open_work_pr만 호출한다. 사람이 치는 pull은 그대로다.
- 날 git push는 이 가드가 막지 못한다. #88로 넘긴다.
- 훅, 토큰, 권한, 샌드박스는 바꾸지 않는다. 같은 세션 id 거르기는 하지 않는다.

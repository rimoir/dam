# 상태 85

## 지금 상태

머지 조건이 모자랄 때와 세션 id가 없을 때 거부하는 실패 검사를 먼저 둔다.

## 결정

- 만든 세션 id는 워커가 연 PR 본문에서 이슈 링크 다음 줄의 `세션 id:`다. 없으면 머지하지 않는다.
- 검증 코멘트 판정은 `judge_verify_comment`만 쓴다.
- 검사 세 개, 다른 세션의 검토 기록, 1분, 충돌 없음이 모두 참일 때만 squash 머지하고 head sha를 고정한다.
- 사람이 치는 pull 본문은 이슈 링크만이다.
- 날 gh pr merge는 막지 못한다. #88이다.
- 훅, 토큰, 권한, 샌드박스는 바꾸지 않는다.

## 다음 할 일

실패 검사가 빨간 것을 확인한 뒤 머지 명령을 구현한다.

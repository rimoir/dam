# 결과 32

## 결과

`board`는 현황판을 읽기로 갱신한다. 상태, 담당, 막힘 칸은 유지하고 GitHub 칸을 붙인다. 실패하면 파일을 바꾸지 않는다. 가짜 어댑터와 gh 읽기가 같은 줄 형식이다.

이 저장소의 이슈 30, 31을 실제로 읽어 임시 현황판에 반영했다. 기록은 `board-flow.txt`다. 사람 계정으로 다시 보는 확인은 HR P 게이트로 남긴다.

## 교훈 후보

- 현황판의 GitHub 칸은 기존 칸 뒤에 붙이면 한 줄 형식을 깨지 않는다. 실패 때는 파일을 아예 쓰지 않는 편이 틀린 상태를 남기지 않는다.

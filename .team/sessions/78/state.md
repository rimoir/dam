# 상태 78

## 지금 상태

Claude 워커 시작을 넣었다. Codex는 미검증이라 띄우지 않는다.

## 결정

- native는 PATH의 claude만 띄운다. 횟수 상한은 40이다. 임시이고 측정 뒤 고친다.
- 작업 폴더 dam-<작업ID>가 있으면 거기서 띄운다. 없으면 노트 루트다.
- poll은 종료 파일로 끝을 보고, collect는 결과 칸 한 줄을 거둔다.
- push, PR, 머지 도구는 ADR 0007 제안대로 넘긴다. 새 토큰, 샌드박스 해제, 새 훅은 없다.
- Codex는 거부하고 띄우지 않는다.
- 로그 도구 칸은 Cursor다.
- HR P PC 결과 칸은 비워 둔다. 시작 시간 중간값은 적지 않는다.

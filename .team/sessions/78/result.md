# 결과 78

## 결과

워커 argv에 `--restricted --strict-mcp-config`를 넣었다. `--mcp-config`는 없다. bare Edit, Write 허용은 작업 폴더 밖을 미리 승인하므로 뺐다. `--disallowedTools Bash`는 거부 규칙으로 남긴다. 끝과 대기는 한 함수가 판단하고 poll과 수거가 같이 쓴다. 공통 gitdir 설정이 바뀌면 문제다. `성공`일 때만 노트 루트에서 결과 파일 하나를 훅과 fsmonitor를 끄고 담는다. 가짜 claude로 시작부터 수거까지 돌려 성공과 결과 줄을 확인했다. 실제 모델은 부르지 않았다.

## 교훈 후보

- 테스트가 제품과 같은 PATH 조회를 쓰면, 도구가 있는 곳에서만 유료 호출이 나간다.
- 워커 작업 폴더와 handle 저장 위치가 같으면 워커가 자기 시작 기록을 읽는다.
- 워커가 결과 칸만 쓰면 수거가 그 폴더의 코드나 git을 돌릴 이유가 없다. 경로를 더 막는 대신 실행을 뺀다.

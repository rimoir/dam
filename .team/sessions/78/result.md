# 결과 78

## 결과

허용 도구는 단위 검증 명령 그대로이고 scripts 와일드카드는 없다. team-session.py 검증은 시작을 거부한다. 없는 실행 파일이면 핸들 없이 거부한다. 결정 줄이나 승인 줄을 바꾸면 결과 칸을 받지 않고 문제로 돌린다. 그 줄은 노트 루트에 되돌려 다음 승인 판정에 읽히지 않는다. 넘기는 글은 맡은 단위의 이름, 의존, 파일, 검증과 결과 칸에 쓰는 법뿐이다. 공개 다섯 칸은 그대로다. 실제 모델은 부르지 않았다.

## 교훈 후보

- 테스트가 제품과 같은 PATH 조회를 쓰면, 도구가 있는 곳에서만 유료 호출이 나간다.
- 워커 작업 폴더와 handle 저장 위치가 같으면 워커가 자기 시작 기록을 읽는다.

# 결과 78

## 결과

native 시작은 계획 단위의 `dam-<작업ID>`에서만 PATH의 claude 절대 경로를 띄운다. 계획에 없거나 작업 폴더가 없으면 거부하고 프로세스를 만들지 않는다. 테스트는 `ORCH_CLAUDE=-`라 실제 도구를 부르지 않는다. Codex는 미검증이라 띄우지 않는다. 실제 모델 호출과 시작 시간 중간값은 하지 않았다.

## 교훈 후보

- 테스트가 제품과 같은 PATH 조회를 쓰면, 도구가 있는 곳에서만 유료 호출이 나간다.
- 워커 작업 폴더와 handle 저장 위치가 같으면 워커가 자기 시작 기록을 읽는다.

# 상태 82

## 지금 상태

verify-comment가 세션 id와 지금 헤드가 있는 코멘트만 검토 기록으로 친다. 없거나 헤드가 다르면 아님 또는 무효다.

## 결정

- 검토 기록은 세션 id, 지금 헤드와 같은 SHA, 확인 방법, 증거 요약이 있는 코멘트다.
- 세션 id가 없거나 형식이 틀리거나 헤드가 없으면 아님이다. 헤드가 지금과 다르면 무효다.
- 판정은 코멘트 문자열과 기대 헤드만 본다. gh를 부르지 않는다.
- 코멘트를 올리는 쓰기는 사람이 명령했을 때만, 검토 기록일 때만 한다.
- 훅과 격리와 토큰은 바꾸지 않는다.

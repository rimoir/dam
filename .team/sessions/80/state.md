# 상태 80

## 지금 상태

verify-judge는 PASS, ISSUES, BLOCKED, 실패 중 하나를 낸다. PASS만 종료 0이다. verify-readonly는 시작과 끝의 코드 경로가 모두 비어야 깨끗이다. 훅 파일은 그대로다.

## 결정

- 판정 함수는 깃과 노트를 읽지 않는다. 워커 `judge`는 그대로다.
- 결과 네 줄은 종류, 헤드 SHA, 확인 방법, 증거 요약이다. 하나라도 없거나 헤드가 다르면 실패다.
- PASS만 통과다. ISSUES와 BLOCKED는 그 단어를 돌려주고 통과가 아니다.
- 읽기 전용은 code-clean과 같은 코드 경로다. 시작 목록과 끝 목록이 모두 비어야 깨끗이다.
- 시작 목록 파일은 `.team/` 아래나 트리 밖에 둔다.
- 훅 파일은 바꾸지 않는다. 결과 기록과 PR 코멘트는 하지 않는다.

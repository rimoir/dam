# 상태 43

## 지금 상태

start-context가 현황판의 열린 줄과 브랜치 끝 이슈 하나의 state.md만 낸다. 검사 14개와 기존 검사 28개가 통과했다. 규칙 원본 앞줄의 읽기 모순을 없앴다.

## 결정

- 구현은 `scripts/session_context.py`에 두고, `scripts/team-session.py`에는 하위 명령 연결만 둔다.
- 임시 상한은 시작 주입 4,000자, 상태 파일 2,000자다. 넘으면 본문 대신 줄이라는 한 줄만 낸다.
- 열린 작업은 브랜치 이름의 끝 숫자다. 끝 숫자가 없으면 열린 줄만 낸다.
- 상태 `완료`와 `닫힘`은 열린 줄이 아니다.
- `summary`는 호환 명령으로 남긴다. 훅 파일은 만들지 않는다.
- 이 세션 로그의 도구 칸은 `Cursor`다. 생성기 템플릿의 도구 이름은 `Claude Code`와 `Codex` 그대로다.

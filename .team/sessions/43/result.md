# 결과 43

## 결과

`python3 scripts/team-session.py start-context`가 현황판의 열린 줄과 브랜치 끝 이슈의 state.md만 낸다. 도구 전환일 때만 로그 마지막 5줄을 더한다. 시작 주입 4,000자 또는 상태 파일 2,000자를 넘으면 줄이라는 한 줄만 낸다. 규칙 원본은 폴더 전체를 읽지 않고 현황판과 상태만 읽게 고쳤다. 훅 파일은 없다.

## 교훈 후보

- 커밋이 없는 저장소에서 `git rev-parse --abbrev-ref HEAD`는 실패한다. 브랜치 이름은 `git branch --show-current`로 읽는다.
- 글자 상한은 바이트가 아니라 문자 수다. 한글 2,000자는 바이트로 세면 상한을 넘긴 것처럼 보인다.
